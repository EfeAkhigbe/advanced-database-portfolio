Portfolio 2: Query Processing and Optimisation

This exercise uses a University Student Result Management
System to demonstrate SQL query processing.

Four SQL queries were executed to retrieve student
information, grades, course averages and high scores.

The queries demonstrate JOIN, WHERE, AVG and GROUP BY.

The EXPLAIN command was used to inspect how MySQL
retrieves records.

An index named idx_student_department was created on
the department_id column.

The index allows MySQL to locate matching department
records efficiently. The dataset is small, so a
measurable improvement in speed was not established.
