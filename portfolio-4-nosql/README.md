Portfolio 4: NoSQL and Advanced Data Models

This exercise demonstrates a document-oriented NoSQL
database using MongoDB Playground.

Five student documents were created. Each document
contains student information and an embedded array
of courses and scores.

Two queries were executed:
1. Retrieve Computer Science students.
2. Retrieve students with scores above 80.

MongoDB is suitable for storing flexible student
records because documents can contain nested data.

Unlike the relational database, course information
can be embedded directly within each student document.

However, embedding can cause data duplication when
course details are shared across many students.

The exercise demonstrates document modelling and
basic querying in a NoSQL environment.
